Email attachments: poll → parse → classify → stream to database

Gmail poll (MailboxPoller), shared extract_document path, optional schema-bound JSON or Nicrron classification via model gateway, target DB writer.

Sequence

sequenceDiagram
  participant P as MailboxPoller
  participant G as Gmail API
  participant X as extract_document
  participant C as Customer mapping
  participant M as Model gateway / Nicrron
  participant W as DB writer
  participant D as Database
  loop every interval
    P->>G: messages.list
    G-->>P: new IDs
    P->>G: messages.get raw
    P->>X: parse
    X-->>P: ExtractedDocument
    P->>W: stream metadata + table rows
    W->>D: INSERT
    opt model gateway
      P->>M: schema + document
      M-->>P: JSON
      P->>W: upsert entity
      W->>D: UPSERT
    end
    opt Nicrron classification
      P->>C: resolve sender
      C-->>P: customer_id + required documents
      P->>M: email + parsed attachments + requirements
      M-->>P: email label + document matches
      P->>W: store classification + per-item compliance
      W->>D: UPSERT
    end
    P->>P: save _state.json
  end
